# SolarDeck REST API

Generated by `node scripts/generate-api-docs.mjs` from the backend itself: 467 endpoints in 55 areas. A running server also serves the interactive reference at `/api/docs` and the schema at `/api/openapi.json`; the full schema is in [openapi.json](openapi.json).

Every endpoint needs a signed-in session (the `pos_session` cookie or `Authorization: Bearer <token>` from `POST /api/auth/login`) unless noted; destructive actions also need a step-up token (`X-Step-Up-Token`). Extra accounts are limited by their role (Settings → Privilege & Security → Users & Roles).

Scripts and other tools sign in the same way: `POST /api/auth/login` returns the bearer token (send `otp` with the current code when two-factor sign-in is on). The *Drivers* column says which hypervisor driver serves each endpoint; *both* means Proxmox VE and SolarOS.

## WebSockets

Each socket also needs the signed-in session: the `pos_session` cookie, or `?token=<bearer token>`. A refused socket closes with code 4401 (not signed in) or 4403 (bad console session or cross-origin page).

| Path | Purpose | Connect with | Drivers |
|---|---|---|---|
| `/api/compute/{guest_type}/{guest_id}/serial` | Out-of-band serial console of a VM or container | Same-origin page only; enable a VM's port first with `POST /api/oob/serial/qemu/{guest_id}/enable` | both |
| `/api/v1/ws/host-shell` | Instant root shell on the host (TopBar, Dock and Control Panel *Host Shell*) | Same-origin page only | both |
| `/api/v1/ws/terminal/{guest_type}/{vmid}` | Text console of a VM (serial), container or the host (`guest_type` `node`, `vmid` 0) | `?session=` from `POST /api/v1/guests/{guest_type}/{vmid}/terminal` (single use, 60 s) | both |
| `/api/v1/ws/vnc/{guest_type}/{vmid}` | Graphical (VNC/RFB) console of a VM or container | `?session=` from `POST /api/v1/guests/{guest_type}/{vmid}/vnc` (single use, 60 s) | both |
